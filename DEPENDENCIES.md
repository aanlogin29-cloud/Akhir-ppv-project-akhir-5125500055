  * CSS (`bootstrap.min.css`): ± 23.5 kB[cite: 1]
  * JS (`bootstrap.bundle.min.js`): ± 58.2 kB[cite: 1]

## Jawaban 4 Pertanyaan Pertimbangan Pustaka:
1. **Mengapa memakai pustaka ini?** Agar komponen interaktif memiliki standar aksesibilitas tinggi dan konsisten tanpa merancang dari nol[cite: 1].
2. **Apakah versi terkunci?** Ya, menggunakan versi spesifik `5.3.3` untuk mencegah perubahan tak terduga[cite: 1].
3. **Bagaimana penyesuaian gayanya?** Gaya kustom ditulis di `style.css` setelah Bootstrap CSS[cite: 1].
4. **Bagaimana pengelolaan API JavaScript?** Seluruh fungsi JavaScript Bootstrap dibungkus terpusat dalam satu modul pembungkus (`ui-pustaka.js`)[cite: 1].
